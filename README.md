# IA-Subway-Surfers
*Projet réalisé lors de ma 2ème année de Licence Informatique (L2).*

## L'histoire du projet
À l'origine, ce projet universitaire devait être un simple exposé libre. Finalement, nous avons décidé d'aller beaucoup plus loin en développant un jeu complet et une Intelligence Artificielle capable d'y jouer !

C'était un vrai défi car c'était **ma toute première expérience avec le langage C#**.

## Concept
Il s'agit d'un mini-jeu inspiré de *Subway Surfer* où il faut esquiver des voitures. Le cœur du projet réside dans l'IA que j'ai développée (visible dans les scripts de ce repository) qui analyse son environnement et prend les décisions pour survivre le plus longtemps possible de manière totalement autonome.

## Technologies utilisées
*   **Langage :** C#
*   **Moteur :** Unreal Engine
*   **Concepts abordés :** Algorithmique, Intelligence Artificielle, Programmation Orientée Objet (POO)
